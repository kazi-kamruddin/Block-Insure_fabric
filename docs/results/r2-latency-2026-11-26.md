## MVCC attribution

The logs do not contain Fabric's exact stale-key diagnostics. Source inspection identifies the shared `oracleRequest` composite key for each request as the common contended object. Reveals also read the claim and may update it during finalization, so the exact invalidating key remains unconfirmed for all 20 rows.
